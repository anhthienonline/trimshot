Privacy

Trimshot collects nothing and sends nothing. This page is short because there is very little to describe.

No network access

There is no networking code in the app. Not disabled, not opt-in — absent. Check for yourself against the source: 

grep -rE "URLSession|URLRequest|NWConnection|socket\(" Sources/

That returns nothing, and continuous integration fails the build if it ever stops returning nothing. There is no account, no telemetry, no crash reporting, no update check, and no analytics.

What the app can see

Trimshot needs macOS Screen Recording permission, because capturing the screen is what it does. With that permission it can read the contents of your displays. It uses that to:

  • grab a full-resolution still of each display when you press the shortcut, held in memory for the length of one capture and released when the overlay closes;
  • read individual pixels from that still for the magnifier and the colour picker;
  • recognise text with Apple's on-device Vision framework when you use OCR.

No audio, despite what macOS asks for

macOS calls the permission Screen & System Audio Recording, and its periodic reminder mentions audio, because that one grant covers both. Trimshot captures still images only — it never enables audio capture, and it has no way to record sound. You can check: capturesAudio appears nowhere in the source.

Where your captures go

Only where you send them — the clipboard when you copy, or a folder you chose when you save (~/Desktop unless you change it). Nothing is written anywhere else, and Trimshot keeps no history of past captures.

What is stored on disk

Preferences only, in the standard macOS location ~/Library/Preferences/com.thienho.trimshot.plist: your shortcut, save folder, image format, and two boolean settings. No capture data.

Text recognition

OCR runs entirely on your Mac through Apple's Vision framework. Images are never uploaded to perform it.

This website

A static page on Vercel. It sets no cookies and loads no third-party scripts, fonts or trackers — its Content-Security-Policy blocks outbound requests entirely. The host, Vercel, keeps standard server-side request logs that include IP addresses, as any web host does — see Vercel's privacy policy. Nothing beyond that is collected, and nothing is combined with anything else.
