Purpose Checking a build against the design it came from.

Trimshot freezes every display the instant you press the shortcut, then lets you select. The pixels you crop are exactly the pixels you saw.

Every reading is in CSS pixels — the unit your design is already in. macOS's own screenshot tool reports device pixels, so a 420 px frame comes back as 840 and you divide by two every time. And it states its own error, measured against Apple's screencapture of the same region, rather than calling itself pixel-perfect.

Why another one

Most screenshot tools are wide. This one is exact.

There are excellent broad capture tools for macOS — several are free and open source, and between them they cover scrolling capture, screen recording, cloud upload and OCR in dozens of languages. Trimshot does none of that, and is not trying to. If breadth is what you need, use one of those.

It exists for one job: checking a build against a design. That job needs a tool whose numbers you can trust, so the accuracy is stated as a measurement rather than an adjective. Every crop is compared against macOS's own screencapture of the identical region; the difference is 0.01 of one 8-bit level, and there are 112 automated checks over the coordinate maths behind it — negative-origin displays, mixed scale factors, and selections spanning two monitors included.

Features

Your design's unit

A 420 px frame reads 420 × 240 px, not 840 × 480. Figma and CSS work in logical pixels; a Retina screenshot is twice that, and every other tool leaves you dividing.

A ruler that reads edges

Hover and it reports the gap the cursor sits in, found from the frozen pixels rather than from your aim. Drag and it dimensions the box — W × H on each axis.

Loupe and eyedropper

An 8× pixel grid follows the cursor with the hex value underneath. Press C to copy it. It reads the frozen bitmap, so the value is the value.

Nine annotation tools

Freehand, line, arrow, rectangle, ellipse, highlighter, text, pixelate for covering a client's data, and place-an-image — which arrives centred, then drags and resizes. Six colours plus any colour you pick.

Vietnamese OCR

Lifts text out of a capture on-device, diacritics intact. Nothing is uploaded to read it.

Adjust to the pixel

Eight resize handles, drag to move, and arrow keys for one-point nudges when the selection has to land on an exact number.

Nothing leaves the machine

No upload, no account and no analytics in the app — there is no networking code in the binary at all, and captures go to the clipboard or a folder you chose. This website does measure its traffic; see Privacy.

Every display, frozen

A full-resolution still of each monitor is grabbed before the overlay appears, so video, menus and the cursor cannot drift underneath your selection.

Stays out of the way

A menu bar icon and one shortcut. No Dock icon, no window, no launch screen.

Install

Four steps, one of them annoying

  1. Download the disk image and drag Trimshot into your Applications folder.
  2. Open it. macOS will refuse the first time — see the note below.
  3. Press ⌃G. macOS asks for Screen Recording access; grant it under Privacy & Security › Screen & System Audio Recording.
  4. Press ⌃G again and drag a selection.

Or with Homebrew

brew tap anhthienonline/trimshot
brew install --cask trimshot

Convenient for installing and updating, but it does not skip the step below: Homebrew quarantines its downloads by default, so an un-notarised build still needs the one-time approval.

The first launch is blocked, and that is expected

Trimshot is signed, but not notarised by Apple — notarisation requires a paid developer account, and this is a small tool given away. So Gatekeeper stops the first launch and says it cannot verify the app is free of malware.

To allow it: open System Settings › Privacy & Security, scroll to the blocked-app notice, and click Open Anyway. macOS 15 removed the older Control-click → Open shortcut, so that panel is the only route. Once per machine.

If you would rather not take that on trust, build it from source instead — it is a few hundred kilobytes of Swift with no dependencies.
