Trimshot

The screen stops. Then you measure it.

A capture tool for macOS built for design QA. It freezes every display before you draw a selection, so the pixels you crop are exactly the pixels you saw — and it reports them in points and pixels, because a Retina screenshot is neither on its own.

What it does

Capture first, decide second

Most overlays float above a live screen. Video keeps playing, menus close, the cursor moves — so the region you finally crop is not the region you selected. Trimshot grabs a full-resolution still of every display the instant the shortcut fires and paints the selection UI on top of that frozen frame.

The magnifier and the colour picker read the same bitmap that gets cropped, so a hex value is the hex value, not an approximation of a moving target. The crop matches macOS's own screencapture of the identical region to within 0.01 of one 8-bit level.

Features

Points and pixels, together

840 × 480 px · 420 × 240 pt — the two numbers you need when checking a build against a Figma frame.

Loupe and eyedropper

An 8× pixel grid follows the cursor with the hex value and coordinate underneath. Press C to copy the colour.

Eight annotation tools

Freehand, line, arrow, rectangle, ellipse, highlighter, text — and pixelate, for covering a client's data before you paste.

Vietnamese OCR

Lifts text out of a capture on-device, diacritics intact. Nothing is uploaded to read it.

Adjust after the fact

Eight resize handles, drag to move, and arrow keys for single-point nudges when a selection has to land on an exact number.

Nothing leaves the machine

No upload, no account, no analytics. There is no networking code in the app at all — captures go to the clipboard or a folder you chose.

Identity

Built from the language of measurement

The mark is the app's own selection UI: four crop brackets around a crosshair, reduced until it still reads at 16 px. The empty middle is the selection — filling it breaks the idea.

Measure magenta has one job — the dimension annotations on this page and nothing else. Design tools colour measurement overlays this way, so it carries meaning rather than decoration; spending it on a button would cost the palette its only signal.

Type is the platform's own: SF Pro for reading, SF Mono for anything that is data — dimensions, hex values, shortcuts, sizes. No webfont, so nothing silently falls back. The full guide is in brand/BRAND.md.
